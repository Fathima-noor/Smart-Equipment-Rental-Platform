# Smart Equipment Rental Platform

## Project Overview

The Smart Equipment Rental Platform is a web-based application that allows customers to rent equipment such as cameras, laptops, projectors, and drones. Vendors can manage their equipment, while administrators and staff can manage bookings, equipment returns, maintenance, and damage reports.

The platform simplifies the equipment rental process by providing equipment management, booking management, payment processing, and rental tracking in one place.

## Features

- **User Authentication:** Secure login and role-based access control.
- **Customer Management:** Browse equipment and manage rental bookings.
- **Vendor Management:** Add, update, and manage equipment listings.
- **Equipment Management:** Maintain equipment details, rental prices, and availability.
- **Booking Management:** Create bookings and track rental status.
- **Payment Integration:** Process rental payments using Stripe.
- **Equipment Handover and Return:** Manage equipment collection and return procedures.
- **Damage Reports:** Record equipment damage and related costs.
- **Maintenance Management:** Track equipment maintenance and repair costs.
- **Admin Dashboard:** Manage users, equipment, bookings, and reports.
- **Responsive Interface:** User-friendly interface built with Angular.

## User Roles

- **Customer:** Browse equipment, book rentals, make payments, and view booking details.
- **Vendor:** Manage equipment listings and rental information.
- **Operations Staff:** Handle equipment handover and return processes.
- **Maintenance Staff:** Manage maintenance activities and repair information.
- **Admin:** Manage users, equipment, bookings, reports, and platform operations.

## API Testing

Use Postman to test the backend REST APIs. Authenticate first and provide the required authorization token when accessing protected endpoints.
